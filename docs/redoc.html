Google

Fluxo OAuth com Google.

Iniciar autenticação com Google

Redireciona o navegador para o Google e define cookies temporários usados na validação do callback.

Responses

Mesmo domínio da página de documentação

/auth/google

Finalizar autenticação com Google

Callback chamado pelo Google. O navegador deve trazer os cookies temporários definidos por /auth/google. code e state são enviados pelo Google; não são valores criados manualmente pelo cliente.

Authorizations:
(googleStategoogleNoncegoogleCodeVerifier)
query Parameters
code
string

Código de autorização, presente quando o usuário autoriza.

state
string

Estado retornado pelo Google, presente no sucesso.

error
string

Erro retornado pelo Google, caso o usuário recuse ou cancele.

Responses

Mesmo domínio da página de documentação

/auth/google/callback

Links

Criação e listagem dos links do usuário autenticado.

Criar link curto

Cria um link público ou protegido por senha para o usuário autenticado. URLs originais aceitam apenas HTTP ou HTTPS e não podem apontar para o próprio domínio curto. Links privados exigem uma senha de pelo menos oito caracteres; ela é armazenada como hash Argon2id.

Authorizations:
userSession
Request Body schema: application/json
required
One of
url
required
string <uri>

URL absoluta HTTP ou HTTPS.

visibility
required
string
Value: "public"

Listar meus links

Retorna somente links pertencentes ao usuário da sessão. A ordenação é por created_at e id, ambos decrescentes. Para continuar, copie next_cursor da resposta anterior para o parâmetro cursor; ele é apenas uma posição de paginação, não uma credencial.

Authorizations:
userSession
query Parameters
limit
integer [ 1 .. 20 ]
Default: 20

Quantidade máxima de links por página.

cursor
string

Cursor Base64URL sem padding recebido em next_cursor.
